# Modern Nature — pratonton laman web

Buka `index.html` dalam pelayar untuk melihat laman ini. Semua gambar disertakan dalam folder `assets`; kekalkan struktur folder apabila memindahkan laman.

Laman dibina menggunakan HTML, CSS dan JavaScript biasa. Fon Google dimuatkan apabila ada sambungan internet; fon sandaran tersedia apabila luar talian.

## Kandungan dan fungsi

- Pengenalan, cerita jenama, koleksi, servis, galeri, proses pertanyaan dan hubungi.
- Penapis galeri, paparan gambar besar, katalog sembilan kategori dan navigasi telefon.

- Paparan responsif dan sokongan tetapan pengurangan gerakan.
